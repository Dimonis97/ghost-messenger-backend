# Ghost Messenger — Python Backend 👻🛡️

**Ghost Messenger Backend** — это серверная часть анонимного Web3-мессенджера  
с end-to-end шифрованием, ephemeral-ключами и Zero-Knowledge архитектурой.

Backend построен на **Python (asyncio)** и обеспечивает:
- безопасную регистрацию через криптоключ  
- обработку зашифрованных сообщений  
- ротацию сессионных ключей  
- минимальное знание сервера о пользователе (ZK-модель)

---

## 🔐 Безопасность

### 🔑 Криптография
- Ассиметричное шифрование: **X25519**
- Симметричное шифрование: **AES-256-GCM**
- Поддержка подписей Ed25519
- Ephemeral ключи → *Forward Secrecy*
- Сессионные ключи → *Быстрая переинициализация*

### 🔒 Zero-Knowledge Архитектура
Сервер НЕ знает:
- номера телефона  
- e-mail  
- реального имени пользователя  
- ни одного их секретного ключа  

Все сообщения зашифрованы на клиенте.  
Сервер хранит только blob данных, не имея возможности их расшифровать.
